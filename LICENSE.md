## License Overview

PSForever is a multiplayer server emulator intended to be run and interacted with over computer networks. Because standard GPLv3 copyleft obligations only trigger upon distribution of binaries/copies to users, the project uses the **GNU AGPLv3** to ensure that any public server running modified versions of PSForever must share its complete source code with the community and connected players.
