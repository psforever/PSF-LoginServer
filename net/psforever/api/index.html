  4.  final class CachedValue[T] extends AnyRef

    A value that is reloaded at most once per ttl, however many callers ask for it.

    A value that is reloaded at most once per ttl, however many callers ask for it.

    This is what keeps public request volume from turning into load on the game world: while a value is fresh every caller gets the same copy, and once it expires concurrent callers share one reload rather than starting one each. A failed reload is not cached; callers are given the last good value instead, so a brief stall in the world does not make the API go dark -- but only while that value is younger than maxStale. After that the failure is reported, rather than old data passed off as current.

  12.  final class PublicApi extends AnyRef

    The public surface of the PSF-HTTP API: rate-limited, safe to serve to the internet.

    The world reads need no credential and change nothing, and every one reads the same cached player list, so request volume never reaches the game world more than once per cache period.   13.  final class RateLimiter extends AnyRef

    A token-bucket rate limit per client address.

    A token-bucket rate limit per client address.

    Each address may make burst requests at once and then requestsPerMinute a minute after that. IPv6 clients are grouped by their /64, because a single host is routinely handed a whole /64 and could otherwise take a fresh bucket for every request.

    Memory is bounded: at most maxTrackedAddresses buckets are held. When the table is full, a new address may take the place of the least recently used one only if that bucket has refilled completely, so forgetting it gives nothing away. Otherwise the newcomer shares a single overflow bucket. Evicting busy buckets instead would let a client that controls many addresses (an IPv6 /48 is 65,536 /64s) cycle through them faster than they are remembered and never be limited at all.

  14.  final class SessionApi extends AnyRef

    Sign-in sessions on the public surface, for the web portal acting on a player's behalf.

    Sign-in sessions on the public surface, for the web portal acting on a player's behalf.

    - POST /v1/sessions signs in with username, password and, for an account that uses TOTP, totp. - DELETE /v1/sessions/current signs this session out; DELETE /v1/sessions signs out everywhere. - GET /v1/me describes the signed-in account. - POST /v1/me/totp starts TOTP enrolment, POST /v1/me/totp/confirm finishes it with a first code, and POST /v1/me/totp/disable turns it off with a current code.

    Every route but sign-in takes the session token as Authorization: Bearer <token>. Sign-ins, and wrong codes when confirming or disabling TOTP, go through the SignInThrottle. Because the portal makes these calls for every player, it must be listed in api.trusted-proxies and send X-Forwarded-For, or every player shares one address's throttle and rate limit.

  15.  final class SessionService extends AnyRef

    Sign-in sessions issued by this server (decisions Q3 and Q7 to Q12).

    Sign-in sessions issued by this server (decisions Q3 and Q7 to Q12).

    A session token is 32 random bytes; only its SHA-256 is stored. Every request re-reads the account, so a change made anywhere, including by the 1.x portal writing to the database directly, takes effect at once: a ban, a password change (detected through a fingerprint of the password hash) or losing GM ends the sessions that change invalidated -- all of them for a ban, the ones signed in before the password change, and the ones carrying GM rights. A session notices on its next request, which is also why a token left over from before a password change cannot end one signed in after it. Sessions also end after idleTimeoutMs unused and maxLifetimeMs after sign-in.

  18.  final class SignInThrottle extends AnyRef

    Slows down repeated failed sign-ins without ever locking an account.

    Slows down repeated failed sign-ins without ever locking an account.

    Failures are counted per client address and per username. The first freeFailures cost nothing; after that each failure makes the next attempt from that address, or for that username, wait twice as long as the last, starting at one second and capped. An account is never locked: once the wait is over, one more attempt is allowed. A success clears the username's count only. Clearing the address too would let someone who owns one working account reset their address between guesses at other accounts.

    A key forgets its failures after SignInThrottle.QuietPeriod without one. Memory is bounded at maxTracked keys per kind. When a table is full, the least recently failed key is forgotten if it is no longer making anyone wait; otherwise the new key is not tracked, so a flood of addresses can cost throttling for newcomers but never locks anyone out.

  22.  final class TrustedProxies extends AnyRef

    Decides which address a request really came from.

    Decides which address a request really came from.

    X-Forwarded-For is written by whoever sends the request, so it is believed only when the connection itself comes from a configured proxy. Even then only the hops that proxy (and any other trusted proxy) appended can be relied on, so the list is read from the right: the first address that is not a trusted proxy is the client. Anything to the left of it was supplied by the client and is ignored. An entry that is not an IP literal stops the walk, and the last trusted hop is used.
