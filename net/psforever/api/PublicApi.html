final class PublicApi extends AnyRef

The public surface of the PSF-HTTP API: anonymous, read-only, rate-limited and cached.

Everything here is safe to serve to the internet. Nothing needs a credential, nothing changes the world, and every route reads the same cached player list, so request volume never reaches the game world more than once per cache period. Callers include the web portal, the launcher and third-party tools; there is no browser CORS, because browsers reach this data through the portal.
