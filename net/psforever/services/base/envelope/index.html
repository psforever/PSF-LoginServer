  6.  trait MessageTransformationBehavior extends GenericMessageEnvelope with GenericResponseEnvelope

    The mechanics of a proper event system envelope.

    The mechanics of a proper event system envelope. The envelope has two forms: the input message envelope and the output response envelope. The event system uses its stamp to mark that the message form converts into the response form when being processed. In terms of proper metaphor, it makes no sense for a post office take a letter out of its original envelope, write a completely different envelope, write a completely different letter, package the new letter in the new envelope, and deliver it is place of the originals. That would be considered fraud.
